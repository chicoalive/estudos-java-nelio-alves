# Estudos Java - Nélio Alves

Repositório com exercícios, exemplos e práticas desenvolvidos durante meus estudos de Java com base nas aulas e propostas do professor Nélio Alves.

## Conteúdos estudados

- Enumeração e composição
- Herança e polimorfismo
- Tratamento de exceções
- Trabalhando com arquivos
- Interfaces
- Generics, Set e Map
- Programação funcional e expressões lambda
- Stream API

## Organização

Os conteúdos estão organizados por seções e exercícios, acompanhando a progressão dos estudos.

## Tecnologias

- Java
- Git
- GitHub

## Objetivo

Registrar minha evolução nos estudos de Java, praticando lógica, orientação a objetos, coleções, manipulação de arquivos e recursos funcionais da linguagem.
